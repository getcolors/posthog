PostHog Package Skill

A reproducible Green workflow for one single-node PostHog product analytics suite, backed by PostgreSQL 17, ClickHouse 24.8, Redis 7.2, and Caddy 2.11.4 on DigitalOcean.

Private service boundary. Only HTTPS (80/443) and key-only SSH are open to the internet. Postgres, ClickHouse, Redis, and internal worker communication remain strictly within the private Docker Compose network.

Quick start

npx skills add getcolors/posthog
cp .agents/skills/package-posthog-green/green ./green
chmod +x green
./green build
./green create --dry-run

Build renders reproducible output and dry-run walks the workflow without provider side effects. Real creation and deletion require explicit authorization.

Architecture and components

Infrastructure

OpenTofu discovers the configured region’s account default VPC and provisions an Ubuntu 24.04 Droplet and firewall. No VPC UUID is hardcoded.

Analytics Engine

Ansible converges Docker Compose with PostHog Web UI and Celery worker, PostgreSQL 17 for relational metadata, ClickHouse 24.8 for columnar events, and Redis 7.2 for cache/queue.

Ingress & TLS

Cloudflare manages DNS and Caddy terminates origin TLS, reverse-proxying traffic to PostHog web on port 8000.

Disaster Recovery

Scheduled systemd timer posthog-backup.timer triggers /usr/local/sbin/posthog-backup to snapshot PostgreSQL and ClickHouse to Cloudflare R2.

Desired state and lifecycle

Non-secret configuration lives in colors.yml. Credentials are provided at runtime via COLORS_PAR_* environment variables.
